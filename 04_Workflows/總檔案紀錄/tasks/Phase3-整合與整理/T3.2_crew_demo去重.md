## 修復步驟

### 步驟 1 — 比對兩目錄

```powershell
$canonical = "D:\我的專案\crew_demo"
$duplicate = "D:\虛擬環境\crew_demo"

Get-ChildItem $canonical -Recurse -File | ForEach-Object {
  $rel = $_.FullName.Substring($canonical.Length)
  $other = Join-Path $duplicate $rel
  if (-not (Test-Path $other)) { Write-Host "ONLY canonical:" $rel; return }
  $h1 = (Get-FileHash $_.FullName -Algorithm SHA256).Hash
  $h2 = (Get-FileHash $other -Algorithm SHA256).Hash
  if ($h1 -ne $h2) { Write-Host "DIFF:" $rel }
}
Write-Host "Compare done."
```

### 步驟 2 — 決定保留位置（建議）

| 角色 | 路徑 | 理由 |
|------|------|------|
| **保留（canonical）** | `D:\我的專案\crew_demo\` | 語意正確（專案目錄） |
| **移除或連結** | `D:\虛擬環境\crew_demo\` | 「虛擬環境」應只放 venv，不應放完整專案 |

### 步驟 3 — 備份後刪除重複

```powershell
$dup = "D:\虛擬環境\crew_demo"
$bak = "D:\虛擬環境\crew_demo.backup_$(Get-Date -Format yyyyMMdd)"
Copy-Item $dup $bak -Recurse
Remove-Item $dup -Recurse -Force
Write-Host "Removed duplicate. Backup: $bak"
```

### 步驟 4 — （可選）建立目錄連結

若仍需從舊路徑存取：

```powershell
# 需管理員權限；擇一
cmd /c mklink /J "D:\虛擬環境\crew_demo" "D:\我的專案\crew_demo"
```
