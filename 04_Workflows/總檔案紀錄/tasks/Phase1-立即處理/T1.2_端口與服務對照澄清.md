# T1.2 — 端口與服務對照澄清

## 摘要

釐清原報告「Dashboard :3000 無法連接」的根因：**端口與服務混淆**；建立正確 URL 對照並驗證各服務連通性。

## 根因分析

原報告 W3-009 測試 `:3000` 失敗，但：

| 服務 | 正確端口 | 根目錄 | 狀態（2026-07-06 複查） |
|------|----------|--------|-------------------------|
| **OmniRoute** Dashboard + API | **20128** | `D:\總大腦加免費token\OmniRoute\` | ✅ 監聽中（`0.0.0.0:20128`） |
| **Open WebUI**（AI_HUB Docker） | **3000** → 容器 8080 | `D:\AI_HUB\docker-compose.yml` | ❌ Docker Desktop 未啟動 |

OmniRoute `.env` 設定：

```
PORT=20128
BASE_URL=http://localhost:20128
```

AI_HUB `docker-compose.yml` 映射：

```
ports:
  - "3000:8080"   # open-webui
  - "7681:7681"   # ttyd
```

**結論：** W3-009 不是 OmniRoute 故障，而是 **測錯端口** 或 **Open WebUI 容器未啟動**。

## 驗收測試

### T12a — OmniRoute Dashboard

**命令：**

```powershell
$r = Invoke-WebRequest -Uri "http://127.0.0.1:20128/" -UseBasicParsing -TimeoutSec 10
Write-Host "Status:" $r.StatusCode "Content-Type:" $r.Headers["Content-Type"]
if ($r.StatusCode -eq 200 -and $r.Headers["Content-Type"] -match "text/html") { Write-Host "T12a PASS" } else { throw "T12a FAIL" }
```

**通過標準：** HTTP 200，`Content-Type` 含 `text/html`。

---

### T12b — OmniRoute API /v1/models

**命令：**

```powershell
$r = Invoke-WebRequest -Uri "http://127.0.0.1:20128/v1/models" -UseBasicParsing -TimeoutSec 10
Write-Host "Status:" $r.StatusCode
if ($r.StatusCode -eq 200 -and $r.Content -match '"object"\s*:\s*"list"') { Write-Host "T12b PASS" } else { throw "T12b FAIL" }
```

**通過標準：** HTTP 200，JSON 含 `"object":"list"`。

---

### T12c — 確認 :3000 語意（預期失敗或 Docker 後成功）

**命令：**

```powershell
try {
  $r = Invoke-WebRequest -Uri "http://127.0.0.1:3000/" -UseBasicParsing -TimeoutSec 3
  Write-Host "T12c: :3000 responded" $r.StatusCode "(Open WebUI running)"
} catch {
  Write-Host "T12c: :3000 not reachable (expected if Docker/open-webui not started)"
}
```

**通過標準：** 理解結果——未啟 Docker 時連線失敗 **不算 OmniRoute 故障**。

---

### T12d — （可選）Open WebUI 啟動後

**命令：**

```powershell
$r = Invoke-WebRequest -Uri "http://127.0.0.1:3000/" -UseBasicParsing -TimeoutSec 10
if ($r.StatusCode -eq 200) { Write-Host "T12d PASS" }
```

**通過標準：** Docker 啟動且 `docker compose up -d` 後 HTTP 200。
