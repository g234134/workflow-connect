# T1.3 — AI_HUB venv 與 crewai 相容性

## 摘要

為 `D:\AI_HUB\main.py` 建立可重複使用的 Python 虛擬環境，解決 Python 3.14 下 `import crewai`（chromadb/pydantic）相容性問題。**不屬 T1.1 config 編碼修復範圍**；T1.1 的 `runtime_ready: false` 由本任務處理。

## 根因分析

| 項目 | 現況 |
|------|------|
| `main.py` | 語法可 compile |
| Python 3.14 | system 環境 `import crewai` 失敗 |
| venv | 尚無穩定、可文件化的 venv 配置 |

## 修復步驟

### 步驟 1 — 選定 Python 版本

建議使用 3.11 或 3.12（crewai/chromadb 生態較穩定），與 `.python-version` 對齊。

### 步驟 2 — 建立 venv 並安裝依賴

```powershell
cd D:\AI_HUB
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -U pip
pip install crewai
python -c "import crewai; print('crewai OK')"
```

### 步驟 3 — 驗證 main.py 可啟動（冒煙）

```powershell
cd D:\AI_HUB
.\.venv\Scripts\python.exe -m py_compile main.py
.\.venv\Scripts\python.exe main.py --help
# 或依 main.py 實際 CLI 調整
```
