# T1.1 — AI_HUB 配置編碼修復

## 摘要

修復 `D:\AI_HUB\config\` 內 JSON 的 UTF-8 BOM 與 `system_prompt.txt` 的 Big5 編碼，使 `config_loader.py` 能以 `utf-8` 正常載入。

## 根因分析

| 檔案 | 問題 | 驗證方式 |
|------|------|----------|
| `settings.json` | 檔首 `\xef\xbb\xbf`（UTF-8 BOM） | `json.load(..., encoding='utf-8')` → **FAIL** |
| `cleaning_rules.json` | 同上 | 同上 |
| `system_prompt.txt` | Big5 編碼，非 UTF-8 | `open(..., encoding='utf-8')` → **FAIL**；`big5` → OK |

**重要：**

- 實際「AI 戰車」pipeline 在 **`C:\Users\666LAG`**，`config_loader.py` 讀取 **`C:\Users\666LAG\config\`**（**無 BOM，已正常**）。
- `D:\AI_HUB\main.py` 現為 CrewAI 示範，**未直接讀** `config/`；但 `D:\AI_HUB\config\` 仍為過期副本，若同步或從 D 槽執行 loader 會失敗。
- `Run_AI_Tank.ps1` 指向 `C:\Users\666LAG`，**不經 D 槽 config**。

## 修復步驟

### 步驟 1 — 備份

```powershell
$src = "D:\AI_HUB\config"
$bak = "D:\AI_HUB\config.backup_$(Get-Date -Format yyyyMMdd)"
Copy-Item -Path $src -Destination $bak -Recurse
Write-Host "Backup: $bak"
```

### 步驟 2 — 執行修復腳本

**建議（保留 JSON 欄位順序與格式）：** 僅 strip 檔首 3-byte BOM，不重新 `json.dump`：

```powershell
# 先檢查
python D:\AI_HUB\scripts\remove_json_bom.py --check-only

# 備份並修復（自動建立 config.backup_YYYYMMDD_HHMMSS）
python D:\AI_HUB\scripts\remove_json_bom.py
```

**替代（會重排 JSON 鍵序，不建議除非需同步結構）：**

```powershell
python -c @"
import json, os
src = r'D:\AI_HUB\config'
for fn in ['settings.json', 'cleaning_rules.json']:
    p = os.path.join(src, fn)
    with open(p, 'r', encoding='utf-8-sig') as f:
        data = json.load(f)
    with open(p, 'w', encoding='utf-8', newline='\n') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
        f.write('\n')
    print('Fixed JSON:', fn)
"@
```

`system_prompt.txt` 若仍為 Big5，另執行 Big5→UTF-8 轉換（本任務複查時 **已為 UTF-8**，無需再改）。
