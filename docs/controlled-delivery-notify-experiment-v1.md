# Controlled Delivery / Notify Experiment v1

> **Ticket**: W7-T3 · controlled-delivery-and-notify-experiment-v1  
> **Date**: 2026-06-10  
> **Status**: Tool-layer experiment (sandbox only)  
> **Scope**: Simulated S15 notify for internal fixtures; no production delivery changes

---

## 1. Purpose

Add a **controlled** delivery / notify experiment layer on the Agent standard line v1 (W6-T3~T9). For **demo_phase** and **sampleco/2026-0001** internal sandbox cases only, the experiment:

1. Reads existing `delivery_signoff.md` and bundle artifacts (`reports/report.json`, etc.)
2. Generates plain-text **client-facing summary** (simulated email / report digest)
3. Writes a **notify payload** to `outbox/<case_ref>/notify_experiment_<timestamp>.json`

**NonScope**

- No real email, Slack, Telegram, or external API calls
- No changes to `notebooks/csv_cleaning/case_delivery_bundle.py` or production delivery scripts
- No enablement for non-allowlist cases (e.g. `acme/2026-0001`)

**Governance alignment**

- R4 (wrong delivery): experiment runs **after** signoff/bundle exist; does not bypass Checkpoint B
- R5 (state loss): outbox JSON provides audit trail for simulated notify
- S15 Client Notify remains human-only in production; this module is **experiment_log** only

---

## 2. Module API

**Module**: `delivery/controlled_notify_experiment_v1.py`

| Function | Description |
|----------|-------------|
| `is_experiment_case_allowed(case_ref, intake)` | Allowlist + `sensitivity=internal` gate |
| `load_delivery_context(case_dir, repo_root=...)` | Read signoff / report / eligibility / bundle paths |
| `generate_client_summary(context)` | Plain-text simulated client message |
| `build_notify_experiment_record(context, ...)` | Assemble outbox JSON dict |
| `run_controlled_notify_experiment(case_dir, dry_run=True, ...)` | End-to-end entry point |

All public paths return stable `dict` with `ok` / `message`.

## 4. CLI

```bash
# Default: dry-run (print summary, no outbox write)
python scripts/run_controlled_delivery_notify_experiment.py --case-dir cases/demo_phase

# Write outbox notify_experiment JSON
python scripts/run_controlled_delivery_notify_experiment.py \
  --case-dir cases/demo_phase --no-dry-run

# JSON output
python scripts/run_controlled_delivery_notify_experiment.py \
  --case-dir cases/demo_phase --format json
```

| Flag | Default | Behavior |
|------|---------|----------|
| `--case-dir` | (required) | Case directory under `cases/` |
| `--dry-run` / `--no-dry-run` | `--dry-run` | When true, skip outbox write |
| `--format` | `text` | `text` or `json` |
