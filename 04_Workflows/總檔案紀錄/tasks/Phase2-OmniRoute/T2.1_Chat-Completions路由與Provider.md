# T2.1 — Chat Completions 路由與 Provider 配置

## 摘要

確認 OmniRoute `POST /v1/chat/completions` 正常回傳 JSON/SSE（非 HTML），並配置至少一個可用 Provider／Model。

## 根因分析

原報告 W3-008 記載「回傳 HTML ("API is running")」。**2026-07-06 複查修正：**

| 測試條件 | 結果 |
|----------|------|
| `GET /v1/models` | ✅ 200 JSON |
| `POST` + `gpt-4o-mini`（無 OpenAI 憑證） | 404 **JSON**：`No active credentials for provider: openai` |
| `POST` + `auto/best-coding`（combo） | ✅ 200 `text/event-stream`（SSE chunks） |
| `GET /` | 200 HTML（Dashboard，**非** chat API 錯誤） |

**根因：** 非 Next.js catch-all 路由 bug（該問題已在 OmniRoute #4674 修復並有單元測試），而是：

1. 使用了 **未配置憑證的 provider/model**
2. 或誤將 **根路徑 HTML** 當成 chat 回應

路由實作：`src/app/api/v1/chat/completions/route.ts` → `handleChat()`。

### 步驟 1 — 確認 OmniRoute 運行

```powershell
netstat -ano | findstr "20128"

若未運行，於 OmniRoute 目錄啟動（依你慣用方式，例）：

```

### 步驟 2 — Dashboard 配置 Provider

1. 開啟 http://127.0.0.1:20128/dashboard  
2. 進入 **Providers** → 新增或啟用至少一個來源（Groq / Nvidia NIM / 免費 tier 等）  
3. 填入 API Key 或 OAuth，狀態為 **Active**  
4. 記下 catalog 中可用的 `model` id（或沿用 combo：`auto/best-coding`）

### 步驟 3 — 以 combo 模型冒煙（無需 OpenAI key）

```powershell
$base = "http://127.0.0.1:20128"
$body = '{"model":"auto/best-coding","messages":[{"role":"user","content":"Say OK"}],"max_tokens":10,"stream":false}'
Invoke-WebRequest -Uri "$base/v1/chat/completions" -Method POST -Body $body -ContentType "application/json" -UseBasicParsing
```

若 `stream:false` 不支援，改用 `stream:true` 並檢查 SSE（見 T21b）。

## 驗收測試

### T21a — Models 列表

**命令：**

```powershell
$r = Invoke-WebRequest "http://127.0.0.1:20128/v1/models" -UseBasicParsing
if ($r.StatusCode -eq 200 -and $r.Headers["Content-Type"] -match "json") { Write-Host "T21a PASS" } else { throw "T21a FAIL" }
```

**通過標準：** 200 + JSON Content-Type。

---

### T21b — Chat Completions（combo，非 HTML）

**命令：**

```powershell
$body = '{"model":"auto/best-coding","messages":[{"role":"user","content":"Reply with exactly: OK"}],"max_tokens":16,"stream":true}'
$r = Invoke-WebRequest -Uri "http://127.0.0.1:20128/v1/chat/completions" -Method POST -Body $body -ContentType "application/json" -UseBasicParsing -TimeoutSec 60
$ct = $r.Headers["Content-Type"]
Write-Host "Status:" $r.StatusCode "CT:" $ct
if ($r.StatusCode -eq 200 -and $ct -notmatch "text/html" -and ($ct -match "event-stream" -or $ct -match "json")) { Write-Host "T21b PASS" } else { throw "T21b FAIL" }
```

**通過標準：**

- Status 200  
- Content-Type **不含** `text/html`  
- 含 `event-stream` 或 `application/json`

---

### T21c — 錯誤路徑仍為 JSON（非 HTML）

**命令：**

```powershell
$body = '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"hi"}],"max_tokens":5}'
try {
  Invoke-WebRequest -Uri "http://127.0.0.1:20128/v1/chat/completions" -Method POST -Body $body -ContentType "application/json" -UseBasicParsing
} catch {
  $resp = $_.Exception.Response
  $sr = New-Object IO.StreamReader($resp.GetResponseStream())
  $txt = $sr.ReadToEnd()
  Write-Host $txt
  if ($txt -match '"error"' -and $txt -notmatch '<html') { Write-Host "T21c PASS" } else { throw "T21c FAIL" }
}
```

**通過標準：** 錯誤回應為 JSON `error` 物件，**不是** HTML 頁面。

## 回滾方案與風險

Provider 配置在 OmniRoute 資料目錄（通常 `./data`）；可在 Dashboard 停用新增 provider，無需還原程式碼。
