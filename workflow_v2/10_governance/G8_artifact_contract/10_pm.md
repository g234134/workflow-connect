## 1. 轨定位

**ART-PM-*** 定义 **artifact owner**（PM 轨主责，见 G7-2 §3.2 `entry_owner_role: pm`）在 AI 导入 artifact 生命周期内必须产出的**范围、澄清与观测计划**交付物。PM 轨**消费** intake／任务卡输入，**对齐** Design 轨 `ART-DES-SPEC`，并为 Eng 轨 `ART-ENG-CTX` 提供 scope 边界；**禁止**将 queue `Status` 或 battle_report `status` 写入 PM artifact 字段。

**角色边界**：本档使用 G7 owner 枚举 `pm`／`orchestrator`；**不**映射 HQ 尚书省／暗部 cabin 全表。尚書省可代行 `pm` 主责，须在 artifact 元数据记 `delegated_by`。

## 4. 分 Artifact 契约

### 4.1 ART-PM-SCOPE — Scope Brief

**目的**：陈述「导入什么」、粗粒度边界与变更类草案；为 `IMP-SCOPE-DRAFT` entry 与 `IMP-SPEC-CLARIFY` 更新提供载体。

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `artifact_id` | ✓ | 单次 AI 导入稳定 ID（与 `ticket_id` 可同可异，须在票内声明） |
| `ticket_id` | ✓ | 关联施工票或任务卡 |
| `import_intent` | ✓ | 一句导入目标（人读） |
| `target_artifact_kind` | ✓ | 目标产物类型（如 doc contract、runbook delta、code module — **逻辑名**，非路径） |
| `in_scope` | ✓ | 粗粒度纳入范围（条目列表） |
| `out_scope` | ✓ | 粗粒度排除范围（条目列表） |
| `primary_change_class` | — | CHG-* 草案或显式 `TBD`（G6-1）；`IMP-SPEC-CLARIFY` exit 前须落定或 defer |
| `secondary_change_classes` | — | 可选；多 class 票须列 |
| `intake_ref` | — | intake 子域引用（**不**把 `accept`／`reject` 写入本 artifact） |

| 类别 | 规则 |
|------|------|
| **blocker** | 缺 `import_intent`／`in_scope`／`out_scope` 任一；`in_scope` 与 `out_scope` 均空；同一 `artifact_id` 重复开户无治理批注 |
| **IMP 门槛** | **`IMP-SCOPE-DRAFT` entry 前**必须就绪；**`IMP-SPEC-CLARIFY` entry 前**须为最新版 |
| **确认方** | **PM 轨主责（`pm`）** 登记；**orchestrator** 抽检 queue／票号对齐 |

---

### 4.2 ART-PM-CLARIFY — Clarification Record

**目的**：记录 open questions 关闭或 defer；支撑 `IMP-SPEC-CLARIFY` → `IMP-AI-READY` 的澄清闭环。

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `artifact_id` | ✓ | 与 **ART-PM-SCOPE** 一致 |
| `open_questions` | ✓ | 列表；每项含 `id`、`question`、`status`（`open` \| `closed` \| `deferred`） |
| `closed_summary` | 条件 | 全部 `closed` 时必填一句汇总 |
| `defer_items` | 条件 | 存在 `deferred` 时必填；每项含 `owner`、`defer_reason`、`target_state` |
| `dependencies` | ✓ | 硬依赖票／artifact 引用（可指向 **ART-DES-SPEC** `dependencies[]`） |
| `acceptance_ref` | ✓ | 验收口径引用（runbook ID、票内 `acceptance_commands` 或 runner 逻辑名） |
| `scope_delta` | — | 相对上一版 **ART-PM-SCOPE** 的变更摘要 |

| 类别 | 规则 |
|------|------|
| **blocker** | 存在 `status: open` 却宣称可进入 `IMP-AI-READY`；`deferred` 缺 `owner` 或 `defer_reason`；硬依赖票 queue `BLOCKED` 未写入本 artifact 阻塞段 |
| **IMP 门槛** | **`IMP-AI-READY` entry 前**：全部 open questions **已关闭**或已登记 defer；**`IMP-SPEC-CLARIFY` exit 前**须更新 |
| **确认方** | **PM 轨主责（`pm`）**；Design 协作者（`design`）对 **ART-DES-SPEC** 一致性会签 |

---

### 4.3 ART-PM-GAPS — 五轨缺口清单

**目的**：显式列出 G8 五轨（PM／Design／Eng／QA／Release）相对本 artifact 的**必填字段缺口**，满足 G7-3 `IMP-SPEC-CLARIFY` exit 条件 ②；**不**重复 Eng／QA 已交付字段表全文。

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `artifact_id` | ✓ | 与 scope 一致 |
| `gap_items` | ✓ | 列表；每项含 `track`（`pm` \| `design` \| `eng` \| `qa` \| `release`）、`artifact_id`（如 `ART-DES-SPEC`）、`missing_fields[]`、`owner`、`target_ticket` |
| `all_tracks_addressed` | ✓ | 布尔；`true` 表示每项 gap 已有 owner 或已标「本票 N/A」 |
| `notes` | — | 一句说明（如「纯文档票，Release N/A」） |

| 类别 | 规则 |
|------|------|
| **blocker** | `gap_items` 为空却存在已知跨轨依赖；`all_tracks_addressed: false` 却 exit `IMP-SPEC-CLARIFY`；缺口仅写 queue `TODO` 而无 artifact 级 owner |
| **IMP 门槛** | **`IMP-SPEC-CLARIFY` exit 前** |
| **确认方** | **PM 轨主责（`pm`）**；**orchestrator** 交叉引用 G8 README 索引 |

---

### 4.4 ART-PM-OBS-PLAN — 观测计划

**目的**：发布后观测窗口与信号定义；支撑 `IMP-OBSERVING` entry。**不**定义 release gate 细则（→ `50_release_owner.md`）。

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `artifact_id` | ✓ | 与 scope 一致 |
| `release_ref` | ✓ | 指向 **ART-REL-EXEC** 或 `release_id` |
| `observation_window` | ✓ | 时长或截止条件（如 `14d`、至 follow-up 票关闭） |
| `signals` | ✓ | 观测信号列表（指标名、日志关键字、反馈渠道 — **无 secret**） |
| `baseline_metrics` | ✓ | 基线摘要或显式「无指标」 |
| `exit_observation_criteria` | ✓ | 正常退出观测的草案条件（与 **ART-REL-OBS** 对账） |
| `follow_up_policy` | — | 非 P0 反馈是否开新票 |

| 类别 | 规则 |
|------|------|
| **blocker** | 缺 `observation_window` 或 `signals`；发布未确认（无 **ART-REL-EXEC**）却进入观测；在本态开展**新 scope** 施工（应新 artifact 或 `IMP-REWORK`） |
| **IMP 门槛** | **`IMP-OBSERVING` entry 前** |
| **确认方** | **PM 轨主责（`pm`）**；**release owner** 确认窗口与发布 ref 一致 |

## 5. PM 轨 Blocker 字段汇总

| Artifact | Blocker 字段／条件 |
|----------|-------------------|
| ART-PM-SCOPE | 缺 `import_intent`／`in_scope`／`out_scope` |
| ART-PM-CLARIFY | 未关闭 open question；defer 缺 owner；依赖 BLOCKED 未记阻塞 |
| ART-PM-GAPS | 缺口无 owner；`all_tracks_addressed: false` 却宣称澄清完成 |
| ART-PM-OBS-PLAN | 无观测窗口；无 release 执行引用 |

---

## 6. 与 Eng／Design／Release 的边界

| 关系 | 规则 |
|------|------|
| PM → Design | **ART-PM-SCOPE** 边界须与 **ART-DES-SPEC** 一致；冲突以 PM scope + Design spec 会签为准 |
| PM → Eng | **ART-ENG-CTX** 的 `allowed_scope` 不得宽于 **ART-PM-SCOPE** `in_scope`（除非 override 留痕） |
| PM → Release | 观测计划 **不**含发布裁决；**ART-REL-DEC** 由 release owner 产出 |
| queue／battle_report | 仅作 blocker **输入**；禁止写入 PM artifact 的 `imp_state` 等价字段 |
