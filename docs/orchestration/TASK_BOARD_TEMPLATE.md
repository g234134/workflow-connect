# 任務板模板（TASK_BOARD_TEMPLATE）

> 複製下方區塊到 [`TASK_BOARD.md`](./TASK_BOARD.md) 使用。  
> **欄位定義**見 §1；**多階段示例**見 §2。

---

## 1. 欄位定義

| 欄位 | 必填 | 說明 |
|------|------|------|
| **TASK_ID** | 是 | 唯一 ID；子任務用 `T4a`、`T4b` |
| **描述** | 是 | 一句可驗收描述 |
| **負責角色** | 是 | `Hermes` / `Cursor-Orchestrator` / `Cursor-Worker` / `小龍蝦` / `你` |
| **狀態** | 是 | 見下方枚舉 |
| **依賴** | 否 | 須先完成的 TASK_ID，多個用逗號 |
| **備註** | 否 | 風險、路徑、BRIEF 連結 |
| **子任務** | 否 | 子 TASK_ID 列表，或 `-` |

### 狀態枚舉

| 狀態 | 含義 |
|------|------|
| `待辦` | 尚未開始 |
| `進行中` | 已派工、執行中 |
| `被阻塞` | 缺依賴、缺確認、環境問題 |
| `待確認` | 等你或 Orchestrator 拍板 |
| `已完成` | 本任務驗收通過 |

## 4. 維護約定

- **Cursor-Orchestrator** 負責更新狀態；Worker 只建議改狀態，不自行標「已完成」主任務。
- 完成子任務後，檢查父任務 `T4` 是否可改 `已完成`。
- 新增任務從 §2 複製；多階段參考 §3。
